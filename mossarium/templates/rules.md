# Mossarium Rules

## Introduction

This document outlines the rules that govern how AI agents and human developers interact with this project. These rules are designed to maintain consistency, quality, and clarity across all changes.

## Core Rules

1. **Compliance First** - All modifications must comply with the constitutional principles
2. **Context Preservation** - Maintain historical context of all code decisions
3. **Incremental Changes** - Make small, focused changes that are easy to review
4. **Documentation Required** - Every change must be accompanied by appropriate documentation

## File Structure Rules

1. **Directory Organization** - All constitutional files must reside in `.mossarium/`
2. **File Naming** - Use consistent naming conventions for all files
3. **Content Standards** - Maintain minimum content standards for each file type

## AI Agent Rules

1. **Understanding Requirement** - AI agents must understand the project context before making changes
2. **Review Process** - All significant changes must go through a review process
3. **Error Handling** - Proper error handling and logging for all operations
4. **Resource Management** - Efficient use of system resources during operations

## Human Developer Rules

1. **Clear Communication** - Provide clear instructions for AI agents
2. **Regular Review** - Regularly review AI-generated changes
3. **Feedback Loop** - Provide feedback to improve AI agent performance
4. **Collaboration** - Work collaboratively with AI agents rather than against them

## Enforcement

Rules are enforced through the `mossarium check` command, which validates that all constitutional requirements are met.
